# 2026-07-10

## 液态玻璃化（Liquid Glass）大改造
用户请求：跳过 impeccable skill（前端 web 工具），直接用 iOS 26 真·Glass API 把 app 所有"边框"改成液态玻璃风格。

### 项目技术栈确认
- iOS deployment target = **26.5**（iOS 26）—— 可用真 Glass API
- Swift 5.0
- 项目用 **PBXFileSystemSynchronizedRootGroup**（Xcode 16+ 同步文件夹），新增 `.swift` 文件放 `NotePatch/` 根目录即可，**无需改 pbxproj**

### 改动
- 新建 `NotePatch/LiquidGlass.swift`：提供 6 个 View modifier（`.liquidGlassCard/Panel/Pill/Banner/Field/StickyFooter`） + 页面背景 `LiquidGlassBackdrop`（渐变 + 光斑，让玻璃可折射）
- `ContentView.swift` 集中替换：
  - `SectionContainer` 内部实现 → `.liquidGlassCard`
  - `LabeledField` 输入框 → `.liquidGlassField`
  - `StatusPill` 药丸 → `.liquidGlassPill(tint:)`
  - `StatusBanner` 错误/成功条 → `.liquidGlassBanner(tint:)`
  - 页面级 `Color(.systemGroupedBackground)` → `LiquidGlassBackdrop`
  - 顶部 bar、OpenClaw 输入栏、设置页账号区 → `.liquidGlassPanel`
  - OpenClaw 消息气泡 → `.liquidGlassCard(tint: bubbleTint)`
  - Chat 按钮 / 主要按钮 `.buttonStyle(.bordered/.borderedProminent)` → `.buttonStyle(.glass/.glassProminent)`（iOS 26 内建）
  - 底部 sheet 工具栏 → `.liquidGlassStickyFooter()`
  - 删除残留 `.buttonBorderShape()`（与 glass 冲突）
  - 错误泡、警告色块统一改用 banner

### 关键技术要点
- iOS 26 `Glass` API：`Glass.regular` / `Glass.clear` / `Glass.regular.tint(Color)` / `.interactive()`
- `.glassEffect(_:in:)` 必须显式给 `Shape`（默认是 Capsule）
- 玻璃需要下方有色彩才能折射——纯白/纯灰页面会"塌"；所以加了 `LiquidGlassBackdrop` 渐变 + 模糊光斑
- 后续优化方向：可用 `GlassEffectContainer` 把多个玻璃视图合并渲染（性能+变形过渡）
