## NotePatch UI 全面重设计（按设计 Brief）

用户提供了一份完整的设计 Brief，要求将全部 UI 从之前的液态玻璃风格改成：
- 暖中性调色板（#F8F9F7 背景，#FFFFFF 卡片，#171717 主文字，#737373 副文字）
- 品牌绿色点缀（#7EB88B，仅 8% 使用率）
- 8pt 网格间距系统
- 极简 Apple HIG 风格——无玻璃、无渐变、无彩色背景
- 白色卡片 + 1px 边框 + 极淡阴影（opacity 8%）
